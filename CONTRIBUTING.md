# Contributing to ChemFit

Contributions to ChemFit are welcome, including bug reports, documentation improvements, feature proposals, and code contributions.

## Questions and bug reports

Before opening an issue, please check the [documentation](https://chemfit.readthedocs.io) and search the [existing issues](https://github.com/MSallermann/chemfit/issues).

When reporting a bug, please include:

- a minimal example that reproduces the problem, if possible;
- the expected and actual behavior;
- the full traceback or relevant error output;
- your Python and ChemFit versions;
- relevant platform or dependency information.

Please open issues through the [GitHub issue tracker](https://github.com/MSallermann/chemfit/issues/new).

## Feature requests

Feature requests are also welcome. Please describe:

- the problem or use case;
- the behavior you would like;
- any relevant alternatives or existing workarounds.

For larger API or architectural changes, opening an issue before implementing the change is recommended.

## Code contributions

When contributing code:

- keep changes focused;
- add or update tests for changed behavior;
- update documentation when public behavior changes;
- make sure the test suite and static type checks pass.

ChemFit supports Python 3.10 and later.

## Code of Conduct

Contributors are expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
